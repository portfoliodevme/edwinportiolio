Featured academic project · Machine Learning

Banking Customer Behaviour Clustering for Fraud Investigation

An unsupervised machine learning project that groups banking customers according to transaction behaviour and identifies unusual behavioural groups that may require further investigation.

View Project GitHub Repository

Technologies

  • Python
  • Pandas
  • NumPy
  • Scikit-learn
  • K-Means
  • Flask
  • Matplotlib

The clustering does not prove that a customer is fraudulent. It highlights behavioural groups for further investigation.
