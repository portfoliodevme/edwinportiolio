About Me

I am Edwin Msilimba, a Computer Science student and software developer at DMI University in Malawi. I am studying for a Bachelor of Science in Computer Science and expect to complete the degree in 2026.

My interests include web and mobile application development, machine learning, software engineering and emerging technologies. I enjoy turning real-world problems into practical software systems, and I keep improving my technical skills through both academic and personal projects.

My approach is to understand the problem first, design a solution, build it, test it and document it, so that the work can be reviewed and reused by others.

Developer Approach

The six steps I follow on a project, from first idea to a working release.

  1. 01

    Understand the Problem

    Find out who the software is for and what it must do before writing any code.

  2. 02

    Design the Solution

    Plan the data, the structure and the interface so the build has a clear direction.

  3. 03

    Build

    Implement the design in small, readable pieces that can be checked as they grow.

  4. 04

    Test

    Run the software with realistic input and fix what breaks before anyone else sees it.

  5. 05

    Document

    Write down how it works and how to run it, so others can review and reuse it.

  6. 06

    Deploy

    Publish the finished work so that it can be opened and used.
